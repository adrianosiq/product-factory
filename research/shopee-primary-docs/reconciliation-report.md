## Version / market notes

- All 35 artifacts are **v2** (`/api/v2/`), captured 2026-09-01 / 2026-09-03,
  page "Last Updated" dates 2026-06 … 2026-08 where shown. No v1 material.
- API-reference pages are `GLOBAL_API` docs that **explicitly enumerate the
  Brazil host and BR-specific fields** (`tax_info` NCM/CFOP/CEST/CSOSN/PIS/COFINS/
  ICMS, `export_cfop`, model-level `gtin_code` "BR local seller", price "two
  decimal places" for BR). Treat endpoint + field facts as `GLOBAL_API` with an
  explicit `BRAZIL` binding; treat eligibility/onboarding as `BRAZIL`.
- No `PRIMARY_CONFLICT` between two primary artifacts except: (1) model count
  `< 20 (50 TW)` vs request text "at most 50"; (2) authorization validity
  `360 days` (auth doc) vs `365 days` (onboarding guide). Both recorded; do not
  pick one — Phase 02.4 to resolve.

## Readiness model

Unchanged. The four dimensions still hold. Primary evidence refines which rules
feed `PUBLICATION_STATUS` (now: resolved `get_item_limit` bounds, `mandatory`
attributes, brand object, `gtin_validation_rule`, leaf category, ≥1 logistics
channel, weight, DTS ≤ category max) and `EXECUTION_STATUS` (app-category
permission, token validity, `item_status` not `*_DELETE`/`BANNED`, warehouse
capability, Go-Live approval). No fifth dimension.
