# Competitor research

last_reviewed: 2026-08-27
classification: INTERNAL methodology (no OFFICIAL ML rule here)

Goal: learn from the market without copying it. Use only when search/browse tools
are available; otherwise skip and note it in `missing_information`.

## What to sample

- 8–15 listings for the same or closely equivalent product.
- Mix: current Buy Box winner (if catalog), top organic results, a couple of
  low-rated listings (to learn what buyers punish).

## What to extract (patterns, not content)

| Dimension | Look for |
|---|---|
| Title structure | Token order, which specs lead, length, recurring keywords |
| Attributes filled | Which optional attributes competitors bother to fill (filter coverage) |
| Positioning | Who they target (pro vs casual, gift, replacement part) |
| Visual presentation | Gallery roles used, dimension shots, in-box shots, variant labeling |
| Highlighted benefits | The 2–3 selling points repeated across listings |
| Q&A | Recurring buyer questions → attribute/description/FAQ gaps |
| Reviews / complaints | Recurring failure themes → return-prevention inputs |
| Price band | Min / median / max; where the Buy Box sits |
| Commercial conditions | Free shipping, Full, installments, lead time |

## Turn findings into actions

- **Pattern worth adopting**: appears across several *successful* listings AND
  matches our real product → apply (tag INTERNAL).
- **One-off quirk**: only one listing does it → ignore unless clearly beneficial.
- **Gap to exploit**: a filter/attribute competitors leave blank that our
  ProductMaster can fill → fill it.
- **Objection pattern**: recurring complaint/question → address explicitly in
  attributes + description "Antes de comprar" + an image.

## Hard rules

- Never copy a competitor's description text, images, bullet lists or A+ content.
- Never reuse competitor photos or rendered assets.
- Never restate a competitor's unverified claim as our own — re-verify against our
  ProductMaster evidence first.
- Distinguish "useful market pattern" from "imitation" in your notes.

## Output

A short `competitor_intel` block: title-structure summary, attributes to add,
benefits to emphasize, objections to preempt, price band, and the source listing
ids/URLs sampled (for traceability, not reproduction).
